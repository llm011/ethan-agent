# Team Manager（团队管理）

面向带团队的 leader。基于 `people-kb` 的人物档案，做四件管理向的事：CR 分析、绩效汇总、任务委派、群消息扫描。识别到的人员事件统一写进人物档案（带工作标签），定时任务和提醒交给 `schedule-manager`。

> 人员事件的**存储格式归 people-kb 管**（`人物 - {姓名}` 档案）；本技能负责识别、统计、汇总、委派。

## 四大能力

### 1. CR 分析

按团队成员统计周度 MR（数量、代码行数、涉及仓库、关联需求），识别 P0/P1 质量问题和正面信号，产出 `CR周报 - {业务名} - {YYYY}-W{NN}`，关键事件同步到人物档案。

### 2. 绩效汇总

从人物档案时间线 + CR 周报，按「产出与交付 / 技术质量 / 主动性与影响力 / 成长趋势」四维度汇总，生成 `绩效草稿 - {YYYY}-Q{N}`。只给建议区间，不做最终判定。

### 3. 任务委派

拆 checkpoint、创建飞书任务和子任务、配节点提醒（提醒走 schedule-manager）。任务状态变化写回人物档案。

### 4. 群消息扫描

定时扫团队群，识别值得记录的人员事件，输出去重候选清单，用户确认后写入人物档案。

## 配置

`~/.ethan/work/team.yaml`——团队信息（成员、业务方向、关注仓库、绩效配置）。模板见 `templates/team.yaml.example`。

## 关联技能

| 技能 | 用途 |
|---|---|
| `people-kb` | 人员事件的档案格式与存储 |
| `schedule-manager` | 节点提醒、群扫描定时任务、CR 周度汇总 |
| `code-review` | CR 数据拉取与分析 |
| `lark-task` / `lark-im` / `lark-doc` / `lark-minutes` | 飞书任务、群消息、文档、妙记 |

## 设计原则

- **不做最终判定**：绩效打分归管理者
- **确认后再创建**：任务/提醒经用户确认
- **隐私边界**：仅存本地知识库
- **客观记录**：人物事件以事实为主
