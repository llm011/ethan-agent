## 示例报告

# DeepSeek V4 Flash vs GLM-5.2 对比调研

## 执行摘要

**DeepSeek V4 Flash 与 GLM-5.2 是 2026 年中期国产大模型两条不同路线：前者以极致性价比和 Agent 特化横扫开发者市场，后者以长程工程能力稳居开源 SOTA。** 两者均为 MoE 架构、1M 上下文，但 V4 Flash 激活参数仅 13B（GLM-5.2 约 40B），API 定价仅为后者的 **1/8 ~ 1/14**（`https://api-docs.deepseek.com/zh-cn/quick_start/pricing`）。反直觉的是：V4 Flash 仅靠后训练优化（架构未变），Agent 能力从预览版 7.3 分飙至 25.2 分，逼近 Opus 4.8 的 25.7（`https://deepseek.ai/blog/deepseek-v4-flash-ga`）。

**结论**：高频 Agent 调用选 V4 Flash，长周期工程任务选 GLM-5.2，两者互补而非替代。

## 写作要点速查

1. **决策优先**：执行摘要放最前，读者只看摘要也能决策。不要把结论埋在最后。
2. **数据可视**：定价、性能、市场等维度，有数值就用 generate_chart 做图。表格 + 图表双呈现。
3. **来源可溯**：每个量化数据后跟 `` `url` `` 或 `[文字](url)`。web_search 卡片的 url 不要丢。
4. **不轻易放弃数据**："未公开"必须是试过官方定价页 + ≥2 个第三方来源后的结论，不是搜 1 次没找到就写的。
5. **篇幅控制**：比纯文字报告长（有图表和表格），但比资料堆砌短。每个章节服务于决策，不放无关信息。
6. **图表数据**：来自调研结果，不要编造。图表是表格的可视化补充，不是独立信息源。
