# 剧本改编指南

## 主题输入

1. 用一句反常识问题、冲突或明确收益开场。
2. 用 2–4 个场景解释核心观点。
3. 用一句总结或行动建议收尾。
4. 对不稳定事实先检索；无法核实时删掉具体数字，不要编造。

## 文章输入

1. 提取作者的中心论点、关键依据和结论。
2. 去掉目录、广告、导航、重复案例和与主线无关的段落。
3. 改写为口语，不逐段朗读原文。
4. 保持观点归属；有争议的判断写成"作者认为"。
5. 把原文保存到项目 `source.md`，URL 同时写进 manifest。

## 节奏（通用）

- 中文常规语速按每秒约 3–4 个汉字估算，仅用于控制初稿长度；最终时长以 TTS 结果为准。
- 60 秒视频建议总旁白 180–240 个汉字，拆成 5–8 个场景。
- 用户指定秒数时把它写入 `targetDurationSec`；字数只用于初稿，实际约束由 TTS 后的时长检查执行。
- 每个场景只表达一个意思，屏幕文本比旁白更短。
- 开场 3 秒内呈现主题，结尾不重复整段内容。

## Per-mode 节奏指南

### news（行业新闻）

- **结构**：事件概要 → 关键数据 → 影响链 → 利弊对比 → 专家观点 → 核心判断
- **节奏**：信息密度高，5–7 场景，50–75 秒
- **数字**：精确到小数点，用 `stat` 展示关键指标
- **视觉**：`kinetic-text` → `stat` → `timeline` → `comparison` → `quote` → `callout`
- **旁白**：每场景 30–50 汉字，简洁有力

### paper（论文讲解）

- **结构**：问题引入 → 核心痛点 → 方法概念 → 流程步骤 → 实验结果 → 结论贡献
- **节奏**：每页一个概念，5–8 场景，60–90 秒
- **术语**：可用英文专业术语（如 Self-Attention、BLEU），屏幕标题保持中文
- **视觉**：`question` → `callout` → `icon-card` → `timeline` → `stat`+`comparison` → `callout`
- **旁白**：每场景 40–60 汉字，注重解释清晰

### kids（儿童教育）

- **结构**：趣味提问 → 知识点 → 互动引导 → 简单解释 → 分步演示 → 关键词回顾 → 鼓励收尾
- **节奏**：慢节奏，6–8 场景，70–100 秒，每页只说一件事
- **语言**：用拟人化、比喻、感叹句；不用专业术语
- **视觉**：`question` → `icon-card` → `question` → `definition` → `steps` → `kinetic-text` → `callout`
- **旁白**：每场景 20–40 汉字，短句为主

## 文案要求

- 使用短句、主动语态和可朗读的标点。
- 数字、英文缩写和专有名词写成 TTS 容易读对的形式。
- 不使用"大家好欢迎来到我的频道"等无信息开场，除非用户要求。
- 不添加未经用户要求的品牌口号、关注引导或水印。
