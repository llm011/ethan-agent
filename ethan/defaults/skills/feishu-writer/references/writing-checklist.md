# 飞书文档发布前 Checklist

> 本文件为 feishu-writer 的按需参考。发布前**必须**逐项核对。

## 结构

- [ ] 文档头部有元信息（作者、时间、状态、读者）
- [ ] 有背景摘要 Callout（蓝色 📌），3 句以内
- [ ] 长文档（>5 个 H2）在元信息后插入目录块

## 标题与层级

- [ ] H1 全文唯一，用名词短语（《XXX 方案设计》）
- [ ] 所有标题不跳级（H1→H2→H3）
- [ ] H2 用动宾或疑问句，H3 用名词或短句
- [ ] 去掉所有章节数字编号（如 `## 1.`）

## 排版

- [ ] 每个 H2 有引导句（加粗核心观点）
- [ ] 单段不超过 5 行
- [ ] 每段加粗不超过 3 处
- [ ] 颜色种类不超过 3 种，每页不超过 5 处
- [ ] Callout 每章节不超过 2 个，连续 Callout 之间有正文间隔
- [ ] Callout 不包裹超过 5 行的大段正文
- [ ] 表格列数不超过 7 列

## 内容

- [ ] 每个论断后有数据/案例/原因/对比中的至少一个（"所以呢"原则）
- [ ] 所有数据有来源或对比基准
- [ ] 估算数据用"约"、"~"标注
- [ ] 严禁"1. 执行摘要"、"总结"等 AI 惯用语
- [ ] 严禁署名（"by AI"）和正文进度信息
- [ ] 标题纯中文或纯英文，不混杂

## 图表

- [ ] 流程图/时序图/ER 图用 Mermaid（飞书原生渲染）
- [ ] Mermaid 节点名用双引号包裹，无斜杠/括号/Emoji
- [ ] 架构图配色按字节现代科技风（#4A90D9/#52C41A/#F5A623/#FF4D4F）
- [ ] 每张图下方加图注：`图 X：[标题]（[来源/日期]）`
- [ ] 大图用折叠块包裹

## 收尾

- [ ] 结尾有总结 Callout（绿色 ✅）和下一步行动项表格
- [ ] 相关链接按"上游依赖 / 下游影响 / 参考资料"分类列出
- [ ] 评审意见用"选中文字 → 评论"，不在正文写"【待确认】"
- [ ] 重要里程碑手动加版本备注（"v1.0 评审通过版"）

## 工程性

- [ ] 文档 Owner 是用户而非 bot（用 `--as user` 创建或 `transfer_owner.py` 转移）
- [ ] 多次注入用 `docs +update --command overwrite` 或 Block ID 原地替换，不一味 append
- [ ] 图片搬运先 `download` 到本地再 `insert`，不复制旧 Token
- [ ] 批量填表 `time.sleep(0.5)` 防 429
