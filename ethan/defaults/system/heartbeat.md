# Heartbeat 任务清单
#
# ┌─ 规范 ─────────────────────────────────────────────────────────────┐
# │ 格式：每行一条任务；`#` 开头的行自动过滤（仅作说明，不执行）        │
# │ 每行格式：`<编号> <[类型]> <指令>`                                  │
# │   编号：行首正整数 + 至少一个空格，唯一且递增（删除后不重排）        │
# │   类型：[script] / [agent:<skill-name>] / [agent:system]            │
# │ 无编号行视为 script（向后兼容旧格式）                                │
# │                                                                     │
# │ 任务类型：                                                          │
# │   [script]              让 Agent 执行 shell 命令/脚本               │
# │   [agent:<skill-name>]  让 Agent 走某技能的流程（流程定义在 SKILL.md）│
# │   [agent:system]        系统级 Agent 指令（不绑定具体技能）          │
# │                                                                     │
# │ 规则：                                                              │
# │   1. 幂等：每条任务必须可重复执行，不报错、不重复产生副作用          │
# │   2. 去重：写入前先检查是否已存在相同 scope 的条目，避免重复         │
# │   3. 简短：[agent:*] 指令一行写完，具体流程在 SKILL.md 中定义        │
# │   4. 状态隔离：任务的状态文件放 {workspace}/system/，不写知识库      │
# │   5. 不写长逻辑：heartbeat 每次全量执行，复杂判断交给 Agent 推理     │
# │   6. 错误自愈：任务失败不应阻塞其他任务（heartbeat 会 catch 异常）   │
# │   7. 通过 heartbeat_add/remove 工具操作，不裸写文件                  │
# │                                                                     │
# │ 示例：                                                              │
# │   1  [agent:work-notes] 检查每日例行状态                            │
# │   2  [script] python3 /path/to/task.py                              │
# │   3  [agent:eigenflux] 执行静默情报搜集                             │
# └─────────────────────────────────────────────────────────────────────┘
